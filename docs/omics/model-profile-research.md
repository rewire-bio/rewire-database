## Interpretation of coverage

`reviewed` means that the narrative statements were checked against the cited primary project documentation, source code or paper. It does not mean that every checkpoint, training datum, licence or claimed capability has been verified. The remaining gaps are displayed with each profile.

`limited` entries preserve specific recorded methods, datasets, splits and evidence locations from the existing catalogue. Their review notes explicitly distinguish inspection of the imported record from fresh full-text architecture review. These entries do not claim to provide a validated architecture, performance advantage or tested application. This is a documented content backlog, not 226 fully researched model monographs.

Most limited entries are paper-specific methods whose archived extracts contain a table row but no checkpoint hash or architecture description. A numeric transcription check cannot fill those gaps. The exact unresolved fields and evidence locations are recorded separately for each entry. Unreported in a legacy extract does not imply unreported in the source paper.
